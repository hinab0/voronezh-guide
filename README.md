# Воронеж без барьеров

Учебный веб-проект на React — путеводитель по городским местам Воронежа с акцентом на доступность информации для людей с инвалидностью и другими ограничениями.

Проект помогает знакомиться с достопримечательностями города и узнавать об условиях доступности перед посещением.

**Технологии:** React, JavaScript, Vite, React Router, Material UI (MUI), CSS.
