# Команды проекта «Воронеж без барьеров»

## 1. Перейти в папку проекта

Если терминал открыт не в папке проекта:

```cmd
cd "%USERPROFILE%\OneDrive\Desktop\WebProject\voronezh-guide-react"
```

Если терминал уже находится в папке проекта, этот шаг пропусти.

## 2. Запустить сайт на компьютере

```cmd
npm run dev
```

Открой адрес, который покажет Vite в терминале.

## 3. Запустить сайт для проверки на телефоне

Компьютер и телефон должны быть подключены к одной сети Wi-Fi.

```cmd
npm run dev -- --host 0.0.0.0
```

Открой на телефоне Network URL, который покажет Vite. IP-адрес может меняться.

## 4. Проверить проект

Сборка:

```cmd
npm.cmd run build
```

Проверка кода:

```cmd
npm.cmd run lint
```

Проверка изменений на ошибки форматирования:

```cmd
git diff --check
```

## 5. Проверить состояние Git

```cmd
git status
```

Посмотреть изменения:

```cmd
git diff
```

## Важно

- `npm run dev` запускает сайт для разработки.
- `npm.cmd run build` проверяет, собирается ли проект.
- `npm.cmd run lint` проверяет код на ошибки и проблемы стиля.
- `git status` показывает, какие файлы изменены.
- Чтобы остановить работающий сервер, нажми `Ctrl+C` в терминале.
